# FDM Suite — Releases para Windows

Repositório público dedicado **exclusivamente à distribuição de instaladores oficiais da FDM Suite para Windows**.

## Versões

Os instaladores são publicados na aba **Releases** deste repositório. Cada atualização recebe uma tag de versão, por exemplo, `v0.20.79.3`.

## Instalação e atualização

1. Abra a seção **Releases**.
2. Selecione a versão desejada.
3. Baixe o arquivo `FDM-Suite-Setup.exe` na área de arquivos (*Assets*).
4. Execute o instalador no Windows.

O **FDM Launcher** pode utilizar o link direto do instalador publicado em cada release, desde que o manifesto oficial da Suite indique a nova versão e seu SHA-256 correspondente.

## Segurança e privacidade

Este repositório **não contém o código-fonte** da FDM Suite, credenciais, chaves de API nem configurações privadas. O desenvolvimento permanece no repositório privado do projeto.

> **Nota:** a publicação de uma release neste repositório, por si só, não ativa a atualização automática para clientes. A distribuição depende da configuração e publicação do manifesto oficial de atualização da FDM Suite.
